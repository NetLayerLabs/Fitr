# Fitr Android shell (`day.fitr`)

Solana Mobile WebView shell (generated by `solana-mobile@0.5.0 webshell init`) around
`https://fitr.day/`, plus the Fitr camera patch (`CameraPermissionGate.kt`, manifest CAMERA
permission, `mediaPlaybackRequiresUserGesture = false`, no pull-to-refresh on `/workout`).

Build, signing, testing and release steps: **[docs/android.md](../../docs/android.md)**.

```bash
FITR_KEYSTORE_PATH=~/.fitr/fitr-release.keystore android/build-release.sh
```

Notes:
- `twa-manifest.json` stores the keystore path used by `solana-mobile webshell build`; update
  `signingKey.path` if you move the keystore (the build script above takes `FITR_KEYSTORE_PATH` instead).
- The keystore and its passwords are never committed (`.gitignore` blocks `*.keystore`/`*.jks`).
- External links outside `fitr.day` open in the system browser; `solana-wallet:` links open the
  installed wallet (Mobile Wallet Adapter).
